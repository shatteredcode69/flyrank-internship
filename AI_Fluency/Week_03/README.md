## 🎨 Task 1: Decide Once: Build Your Identity Kit

A highly technical, lightweight aesthetic designed to load fast and prioritize content, stripping away heavy decorative elements in favor of clean architecture.

*   **Heading Font:** `Inter` (Clean, geometric, highly legible for technical titles).
*   **Body Font:** `JetBrains Mono` (Brings a structured, developer-focused aesthetic to technical write-ups and case studies).
*   **Color Palette:**
    *   **Background:** Near-White (`#FAFAFA`)
    *   **Body Text:** Slate Black (`#1E293B`)
    *   **Borders/Subtext:** Ash Gray (`#94A3B8`)
    *   **Accent:** Cloud Orange (`#EA580C`) – Used sparingly for active links and primary buttons.
*   **Logo/Favicon:** A minimalist typographic monogram: **`<ma />`** set in `JetBrains Mono` bold, colored in Cloud Orange.
*   **Style Note:** 
    > Fonts: Inter & JetBrains Mono. Palette: #FAFAFA, #1E293B, #EA580C. 
    > Mood: Fast, lightweight, and engineered for performance, prioritizing architectural clarity over visual clutter.

## 🖼️ Task 2: Kill your darlings: Curate Your Images

The portfolio visual strategy heavily prioritizes real-world technical execution over generated metaphors.

### The Rejection Note

**Rejected Image:** An AI-generated, highly detailed cyberpunk-style image of a glowing server rack intended for the hero section.
**Why it was rejected:** It was visually heavy, consumed too many browser resources, and felt like a generic tech cliché. It clashed with the lightweight, minimalist aesthetic of the identity kit. I chose a subtle, low-contrast geometric texture instead, which frames the actual work without competing for the user's attention.
