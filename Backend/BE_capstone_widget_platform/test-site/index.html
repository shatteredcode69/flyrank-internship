Welcome to Acme Bakery's homepage. This file lives in /test-site and is served from a completely different origin (a second local port, e.g. http://localhost:5500) than the widget API (e.g. http://localhost:4000) — exactly what the capstone brief calls for: "the customer site is a plain HTML file opened from a different origin."

Below, our marketing team pasted the one-line embed snippet they got from the FlyRank dashboard. Everything from here down — the popup, the config fetch, the submission — is the widget platform reaching across origins into a page it does not own.

How to use this page:
  1. Start the API: npm run dev (or docker compose up)
  2. Create a widget via the API or npm run seed
  3. Replace the data-widget-id value below with your real widget id
  4. Serve this folder on a different port: npm run test-site → http://localhost:5500
  5. Open that URL — the widget should appear in the bottom-right corner
