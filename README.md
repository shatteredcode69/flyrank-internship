## 📌 About This Repository
This repository serves as my living portfolio and technical deliverable for the **FlyRank Internship Program**. Over the course of 8 weeks, I designed, built, and deployed scalable backend services, orchestrated databases, and deeply integrated AI Model Context Protocols (MCP) into production-ready workflows.

## 🧭 How to Navigate
Every directory in this repository is self-contained. Inside each weekly folder, you will find:
1. **Source Code:** Heavily commented, functional code for that week's assignment.
2. **Dedicated Documentation:** A specific `README.md` containing execution instructions, architecture overviews, and proof of successful deployment.
